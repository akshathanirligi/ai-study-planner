# AI Study Planner 🎓

An intelligent full-stack study planner and productivity web application built with the MERN stack (MongoDB, Express, React, Node.js).

## 🚀 Key Features

- 📝 **Task Management**: Create, edit, prioritize, and track deadlines for study tasks.
- 📊 **Study Analytics**: Visual insights with Recharts including completion status and weekly study charts.
- ⏱️ **Pomodoro Timer**: Dedicated focus timer with sound alerts to keep study sessions productive.
- 🧩 **Relaxation Mini-Game**: Interactive memory game for quick brain breaks between study sessions.
- 🤖 **AI Study Assistant**: Contextual study tips and recommendations tailored to study goals.
- 🌓 **Dark & Light Mode**: Seamless theme toggling with accessible styling.
- 🔐 **Authentication**: Secure JWT authentication for user accounts.

## 🛠️ Tech Stack

- **Frontend**: React, React Router, Recharts, Axios, CSS3
- **Backend**: Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs

## 🏁 Getting Started

### 1. Server Setup
```bash
cd server
npm install
node server.js
```

### 2. Client Setup
```bash
cd client
npm install
npm start
```
